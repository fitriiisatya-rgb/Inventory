Export Data Legacy (localStorage)

Aplikasi legacy menyimpan datanya di localStorage browser, bukan di server. Alat ini membaca semua key localStorage yang ada dan menghasilkan satu file JSON yang bisa diupload ke wizard Tools → Import Data Legacy pada aplikasi baru.

Penting — soal origin (asal domain/file): localStorage terikat ke origin (domain+port) yang sedang dibuka di tab browser. Halaman ini hanya bisa membaca localStorage aplikasi legacy jika dibuka dari origin yang sama (mis. taruh file ini di folder yang sama dengan aplikasi legacy, lalu buka melalui server yang sama). Kalau itu merepotkan, gunakan Cara 1 (Bookmarklet) atau Cara 2 (Console) di bawah — keduanya dijalankan langsung di tab aplikasi legacy yang sedang terbuka, jadi originnya otomatis benar.

Cara 1 — Bookmarklet (paling mudah)

1. Seret tombol biru di bawah ini ke bar bookmark browser Anda (atau klik kanan → copy link, lalu buat bookmark baru dan tempel sebagai URL-nya).

2. Buka aplikasi legacy di tab browser seperti biasa.

3. Klik bookmarklet tersebut. File JSON akan otomatis ter-download.

⬇ Export Data Legacy

Cara 2 — DevTools Console (kalau Cara 1 tidak bisa)

1. Buka aplikasi legacy di tab browser.

2. Tekan F12 (atau klik kanan → Inspect) untuk membuka DevTools, lalu pilih tab Console.

3. Salin script di bawah ini, tempel ke Console, tekan Enter.







Cara 3 — Jalankan langsung dari halaman ini (hanya jika origin sama)

Setelah file JSON terdownload


Buka aplikasi baru → login sebagai SUPERADMIN → menu Tools → Import Data Legacy → upload file JSON hasil export ini. Wizard akan menampilkan daftar key yang ditemukan di dalam file dan meminta Anda memilih mana yang berisi data Master Barang dan mana yang berisi data Stock, lalu menampilkan preview sebelum commit apa pun ke database. Tidak ada perubahan yang dilakukan pada aplikasi legacy oleh alat ini — hanya membaca (read-only).
